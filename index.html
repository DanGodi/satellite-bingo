🛰️ Segmentation Bingo

An AI-powered game using satellite imagery and object detection

Welcome to the Game!

This game uses artificial intelligence (Segment Anything Model 3) to detect objects in satellite images. Mark your bingo card as events fire, and be the first to complete your card to win!

How It Works

  1. Host generates balanced bingo cards (Monte Carlo algorithm)
  2. Game uses AI-detected objects in satellite images (ships, cars, pools, etc.)
  3. Players mark matching events on their cards
  4. First player to complete their card wins!

Built with satellite imagery from USGS and AI object detection
