🛰️ Segmentation Bingo

An AI-powered game using satellite imagery and object detection

Welcome to the Game!

A multiplayer Bingo game played with satellite imagery. AI analysis (SAM 3) determines which objects appear in each image — ships, cars, buildings, pools — and your card marks automatically. Play with friends across any network using a 6-character game code. No installation required.

How This Game Was Created

🤖 The AI: SAM 3

Segmentation is a computer vision technique where an AI identifies and outlines every object in an image. This game uses SAM 3 (Segment Anything Model 3) by Meta, run offline against all 36 images before the game. The results — object counts per image — are stored in a JSON file that the web app reads. The model does not run live during gameplay.

🛰️ The Dataset

The game uses 36 satellite images from the USGS. SAM 3 was used to detect which objects appear in each image and how many:

  • Ships and maritime vessels
  • Cars and vehicles
  • Pools and water features
  • Buildings and structures
  • Trees, forests, and vegetation
  • Roads and parking lots

Example: one of the 36 satellite images used in the game

🎲 Fair Card Generation

When the host starts the game, bingo cards are generated using a Monte Carlo algorithm that ensures all cards are statistically balanced. Each player has roughly the same expected number of turns to win, regardless of which card they get.

💻 Open Source

Built with vanilla HTML, CSS, and JavaScript — no framework, no server. Multiplayer sync uses WebRTC via PeerJS for direct peer-to-peer connections. View the source on GitHub.

📋 How a Round Works

  1. Host opens host.html and shares the 6-character game code
  2. Players open player.html, enter the code and their name, and click Join & Ready
  3. Host clicks Start Game — each player receives a unique, balanced bingo card
  4. Host reveals satellite images one at a time with Next Image
  5. Pre-computed AI analysis determines which objects appear in each image — matching squares mark automatically
  6. Players can also click squares manually if the AI missed something
  7. When all 10 squares are marked, click CLAIM BINGO! — the host verifies the win
  8. After 3 verified winners, the game ends and shows a progress chart for all players

🎮 For the Host

  • Open Host Game — a 6-character game code appears automatically
  • Copy and share the code with players (use the 📋 Copy button)
  • Wait for players to join; once 2 or more are ready, click Start Game
  • Click Next Image to reveal each satellite image
  • Watch per-player progress bars update in real time
  • The game ends automatically after 3 players have their BINGO verified

👤 For Players

  • Open I'm a Player from the home page
  • Enter the 6-character game code from the host, then your name
  • Click Join & Ready and wait for the host to start
  • Your unique bingo card appears automatically when the game begins
  • Squares mark themselves as each image is revealed
  • Click any square manually if you think the AI missed an object
  • When all 10 squares are marked, click CLAIM BINGO!

💡 Good to Know

  • Works across different networks — no LAN required
  • Cards are balanced so every player has a similar expected win time
  • The AI ran offline before the game — it does not process images live
  • After 3 winners are verified, everyone sees a progress chart
