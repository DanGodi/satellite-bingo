How This Game Was Created

🤖 What is AI Segmentation?

Segmentation is a computer vision technique where an AI model identifies and outlines every object in an image. Our game uses SAM 3 (Segment Anything Model 3), a state-of-the-art model developed by Meta that can detect and label objects in any image.

🛰️ The Dataset

This game uses 36 satellite images from the USGS showing different locations on Earth captured from space. The AI detects what objects appear in each image:

  • Ships and maritime vessels
  • Cars and vehicles
  • Pools and water features
  • Buildings and structures
  • Trees, forests, and vegetation
  • Roads and parking lots

Example: A satellite image analyzed by AI

🎲 Fair Card Generation

Bingo cards are generated using a Monte Carlo algorithm to ensure all cards are statistically balanced. This means each player has roughly the same chance of winning, regardless of which card they get.

💻 Open Source

This game is built with vanilla HTML, CSS, and JavaScript. No servers needed — everything runs in your browser using WebRTC for peer-to-peer connections. View the code on GitHub.

📋 Game Rules

  1. Host generates balanced bingo cards using a Monte Carlo algorithm
  2. Players join with a 6-character game code and enter their name
  3. Host reveals satellite images one at a time
  4. An AI model (SAM 3) detects objects in each image
  5. When detected objects match your bingo card events, your squares auto-mark
  6. You can also manually mark squares if you spot objects the AI missed
  7. First player to complete their card claims BINGO and wins!

🎮 For the Host

  • Go to Host Game on the home page
  • Share the 6-character game code with players
  • Wait for players to join and mark themselves as ready
  • Click Start Game to begin
  • Click Next Image to reveal satellite images one by one
  • Watch the player progress bars as they mark squares
  • When a player claims BINGO, the system verifies their win
  • Game ends when 3+ players win — see the final progress chart!

👤 For Players

  • Go to I'm a Player on the home page
  • Enter the 6-character game code from the host
  • Enter your name (max 20 characters) and click Join & Ready
  • Wait for the host to start the game
  • Receive your unique bingo card
  • Watch as squares auto-mark when AI detects matching objects
  • Manually click squares if you spot objects the AI missed
  • When all 10 squares are marked, click CLAIM BINGO!
  • The host will verify your win

💡 Tips for Success

  • Each game generates a unique, balanced set of bingo cards
  • You can play with 2+ players on different networks
  • Watch the host's screen to see which objects are detected each turn
  • The AI might miss some objects — use manual marking to help!
  • The first verified winner completes their card and claims BINGO
  • After 3+ players win, the game ends and shows everyone's progress chart
